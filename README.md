# Student Management App

A simple responsive web application for managing student records.

The application allows users to view, add, search, filter, and delete student records.

## Features

- Display student records
- Add new student
- Validate required fields and age
- Search students by name
- Filter students by course
- Delete student records with confirmation
- Responsive layout for desktop and smaller screens

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run the Application

1. Download or copy the StudentManagementApp project folder.
2. Make sure all project files are in the same folder.
3. Open the project folder.
4. Open `index.html` using Google Chrome.
5. The Student Management App will open in the browser.

## How to Use the Application

- Click **+ Add Student** to add a new student record.
- Enter the student's name, course, and age.
- Click **Add Student** to save the record.
- Use the search field to search for a student by name.
- Use the course dropdown to filter students by course.
- Click **Delete** to remove a student record.
- Confirm the deletion when the confirmation message appears.
